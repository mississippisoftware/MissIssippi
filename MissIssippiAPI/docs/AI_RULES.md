# AI Rules

## Strict Step Mode
Work only on the current step defined in CURRENT_STEP.md. Do not implement anything beyond it.

## Feature Scope
Do not add features, abstractions, or capabilities beyond what the current step requires.

## Architecture
Do not change architecture unless explicitly asked.

## No Duplication
Do not create duplicate services, controllers, or pages. Check what already exists before creating anything new.

## Prefer Modification
Prefer modifying existing files over creating new ones.

## Before Writing Code
List all files that will be created or changed. Wait for confirmation if the scope is unclear.

## When Unsure
Ask the user rather than making assumptions.

## After Each Step
Update PROJECT_PLAN.md to mark the completed step and confirm the next current step.
